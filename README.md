# Фен-стайлер 2 в 1 — слайдер по скроллу

Тестовое задание: адаптивная вёрстка трёх слайдов по [макету Figma](https://www.figma.com/design/oWgQN89NN4VFIixErX21fh/Hair_Styler_TEST--Copy-?node-id=31807-1408), переключение слайдов скроллом и боковое колесо с иконками на десктопе.

**Стек:** Vite, React 19, TypeScript, Tailwind CSS 4. Отдельных JS-библиотек для анимаций нет: всё сделано на CSS-переходах и нативном scroll-snap.

## Запуск

```bash
npm install
npm run dev        # дев-сервер на http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # просмотр собранной версии
```

Сборку `dist/` нужно открывать через статический сервер (`npm run preview` или любой другой): через `file://` браузер не загрузит модули.

## Что сделано

### Десктоп (от 1024 px)

- Секция высотой в три экрана. Внутри неё сцена `sticky` на весь экран, а у каждого слайда свой невидимый якорь высотой 100vh.
- На `html` включён `scroll-snap-type: y mandatory`, у якорей стоит `scroll-snap-stop: always`. Один жест колеса или тачпада переключает ровно один слайд, даже при сильном свайпе. Клавиатура (стрелки, PageUp/PageDown, пробел) работает нативно.
- Активный слайд вычисляется по положению скролла. Новая карточка въезжает в центр снизу при скролле вниз и сверху при скролле вверх. Уходящая карточка уменьшается и гаснет. Заголовки, плашки и звёзды появляются с небольшой задержкой.
- **Колесо.** На кольце 21 иконка: три иконки слайдов повторяются по кругу. Колесо поворачивается на один шаг вместе со сменой слайда: при скролле вниз по часовой стрелке, при скролле вверх против.
  - Иконка текущего слайда встаёт по центру колеса, выдвигается наружу, увеличивается и «зажигается» белым. Рядом появляется её подпись.
  - Видны только активная иконка и две соседние, остальные плавно гаснут на краях дуги.
- **Клик по иконке** поворачивает колесо к ней и прокручивает страницу к нужному слайду. Пока идёт программный скролл, промежуточные слайды игнорируются, поэтому колесо не дёргается.
- Перезагрузка страницы посередине прокрутки открывает правильный слайд. При ресайзе окна страница выравнивается по текущему слайду.

### Мобильная версия (до 1023 px)

- Три слайда идут друг под другом, как в мобильном макете. Колеса нет, по заданию оно только для десктопа.
- Вёрстка резиновая: всё масштабируется от ширины экрана с базой 320 px макета. Начиная с 480 px колонка перестаёт расти и встаёт по центру, а фоны слайдов остаются на всю ширину.
- При появлении слайда в зоне видимости его содержимое плавно проявляется.

### Масштабирование

Размеры пишутся в пикселях макета обычными классами Tailwind: `w-674`, `top-254`, `fs-48`. Чтобы это работало, внутри сцены переопределена переменная `--spacing`, через которую Tailwind 4 считает все отступы и размеры:

- **десктоп:** `min(100cqw / 1920, (100cqh - 80px) / 800)`. Композиция сохраняет пропорции макета 1920 и всегда помещается в экран по высоте;
- **мобилка:** `100cqw / 320`.

Для размера шрифта и скругления добавлены свои утилиты `fs-*` и `radius-*` (см. `src/styles/index.css`).

### Доступность

- Иконки колеса — это кнопки с `aria-label` и `aria-current`. Скрытые иконки убраны из табуляции.
- Неактивные карточки помечены `inert`.
- При `prefers-reduced-motion` анимации отключаются.

## Структура

```
src/
├── assets/            картинки (webp) и файлы шрифта
├── components/
│   ├── icons/         глифы иконок колеса, цвет через currentColor
│   └── ui/            переиспользуемые Pill, StarBadge, Glow
├── hooks/             useMediaQuery, useRevealOnce
├── sections/
│   └── ProductShowcase/
│       ├── ProductShowcase.tsx   выбор десктопной или мобильной версии
│       ├── desktop/              сцена, карточка, колесо, логика скролла
│       ├── mobile/               обёртка мобильного слайда, плашка с иконкой
│       └── slides/               контент слайдов: по папке на слайд,
│                                 в каждой Desktop- и Mobile-версия,
│                                 index.ts — конфиг (подписи, иконки)
├── styles/index.css   тема Tailwind: цвета, шрифты, тени, утилиты
└── utils/
```

Типы и интерфейсы пропсов лежат в `types.ts` рядом с компонентами своей папки и подключаются через `import type`.

## Шрифты

В макете используется **Euclid Circular A**, это платный шрифт. В `@font-face` сначала ищется локально установленный Euclid Circular A SemiBold. Если его нет, подставляется Manrope Bold из `src/assets/fonts` — он ближе всего по пропорциям и есть кириллица. Наборный текст — Montserrat Medium, как в макете.

## Картинки

Картинки выгружены из Figma в исходном качестве и пережаты в WebP: около 0,5 МБ вместо 19 МБ PNG. Размытые эллипсы из макета (`blur(334px)`) заменены радиальными градиентами: они выглядят так же и не тормозят анимации.
